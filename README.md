# Goldish

Лёгкий «легитный» клиент для Minecraft **1.21.11** (Fabric, Java 21).

## Лаунчер

Готовый графический лаунчер Goldishka находится в папке [`loader/`](loader/README.md). Он сам
скачивает Minecraft, Fabric, ресурсы и Fabric API, ставит Goldish и запускает игру.

- Готовая сборка: `loader\dist\Goldishka Loader\Goldishka Loader.exe` (нужна только Java 21).
- Из исходников: `loader\Goldishka Loader.pyw` (нужны Python 3.10+, PyQt5 и Java 21).

Никаких читов, ломающих игру: только то, что может сделать человек руками — доводка прицела,
авто-удар по цели в поле зрения, защита друзей и подсказки по булаве. Плюс собственный стек 2D-рендера,
ClickGUI и HUD.

## Возможности

### Бой
| Модуль | Что делает |
| --- | --- |
| **AimAssist** | Плавно доводит прицел к ближайшей точке хитбокса цели — каждый кадр, без рывков на 20 Гц. Больше не смотрит на центр модели или ник над головой. Настройки: дистанция, FOV, скорость, рандомизация, вертикаль, цели (игроки/мобы), сквозь стены, пауза при использовании предмета, режимы Smooth/Linear. |
| **TriggerBot** | Бьёт, когда прицел попадает на цель в радиусе. Задержка и проверка друзей. Криты: **Off** — обычные удары, **Smart** — сам сбрасывает спринт и прыгает под крит (если крит невозможен — через 900 мс бьёт обычно), **Only** — бьёт только тогда, когда ванильный крит реально возможен. |
| **NoFriendDamage** | Отменяет удар по игроку из списка друзей. |
| **MaceHelper** | Подсказывает/подготавливает момент удара булавой (падение, крит, кулдаун). |

### Движение
| Модуль | Что делает |
| --- | --- |
| **AutoSprint** | Сам включает спринт. **Keep Sprint** — удерживает флаг спринта каждый тик, даже если голод низкий, игрок бьёт или упирается в стену. Дополнительно: **Only Moving** (только при движении вперёд), **While Using Item** (спринт при еде/блоке). |

### ESP и NameTags
| Модуль | Что делает |
| --- | --- |
| **ESP** | Рамка вокруг сущностей в трёх режимах: **Box** — настоящая 3D-коробка по хитбоксу (все 12 рёбер), **Chams** — видимые грани заливаются полупрозрачным цветом, **Corners** — 2D-уголки. Настройки цвета, толщины линии, прозрачности заливки, дистанции, игроков/мобов и «сквозь стены». |
| **NameTags** | Над головой: ник, текущее HP и полоса здоровья; над карточкой — иконки надетой брони с полосками прочности; под ногами — предмет в главной руке. Настройки дистанции, масштаба, отображения HP/брони/предмета, фона и «сквозь стены». Ванильные таблички у этих сущностей скрываются, поэтому дублей нет. |

### HUD (модуль **Hud** в категории Render)
Все элементы HUD — один модуль `Hud`, у каждого виджета свой переключатель. Общий стиль:
«стеклянные» карточки с мягкой тенью, верхним бликом, тонкой рамкой и градиентом в цвете темы —
один дизайн-язык у всех элементов (`HudStyle`).

* **Watermark** (левый верх) — компактная «стеклянная» полоска: значок-прицел, градиентный логотип, версия
  и живые статы **FPS**, **PING**, **POS** с цветной статус-точкой (зелёная → жёлтая → оранжевая).
  Стили: **Card**, **Slim** (без карточки), **Full** (крупнее), **Graph** (плюс мини-график FPS).
  Переключатели: логотип, версия, координаты, фон, тень. Пинг в одиночной игре не показывается.
* **Potions** (левый низ) — строки эффектов: иконка эффекта в цветной плитке с кольцом-таймером
  (пустеет к концу), имя, время рядом и уровень справа в цвете темы (в последние секунды время краснеет
  и мигает).
* **ModuleList** (правый верх) — одна карточка со списком включённых модулей: строки выровнены по правому
  краю, у каждой градиентная акцентная линия; суффикс приглушён, длинные названия обрезаются с `…`.
  Строки быстро появляются/уезжают при включении модуля и скользят при пересортировке. Список сам
  отодвигается от ванильных иконок эффектов.
* **TargetHUD** — карточка цели: настоящая голова игрока в акцентном кольце (у мобов — иконка-силуэт), имя
  и HP системным шрифтом (Segoe UI и подобные, не ванильный битмап), «стеклянная» полоса HP с плавной
  анимацией и поглощением, броня с полосой прочности и дистанция до цели.

**Настройки HUD:** `HUD scale` (0.5–2.0) и `HUD Animation` (плавные появление и исчезновение строк).
Позиции по умолчанию: ватермарк и потионы слева, список модулей справа сверху, TargetHUD по центру снизу;
HUD скрывается, пока открыт любой GUI, и остаётся видимым в чате — это и есть редактор.

* **TargetESP** — подсветка цели в четырёх 2D-стилях и одном 3D:
  **Circle** (сканирующее кольцо идёт от ног к голове с затухающим трейлом),
  **Square** (угловые скобки вокруг хитбокса с мягким свечением),
  **Souls** (роящиеся частицы вокруг тела),
  **Constellation** — созвездие: наклонённая орбита из звёзд, соединённых линиями, со свечением; звёзды
  пульсируют, кольцо медленно вращается и «дышит», а при получении урона палитра краснеет.
  Настройки: **Stars**, **Star orbit**, **Star size**, **Star glow**, **Star lines**, плюс общие цвет,
  размер, скорость и диапазон;
  **Lightning** — молнии в 3D-проходе мира (две проходки по глубине, «сквозь стены»).

**Перетаскивание HUD:** откройте чат (**T**) — видны **все** элементы HUD, включая выключенные: они
подсвечиваются пунктирной акцентной рамкой и подписями с точкой-статусом (у выключенных стоит `(off)`).
Тянуть можно любой из них,
позиция сохраняется в конфиг сразу после отпускания кнопки, набор текста в чат при этом работает как обычно.
Если у элемента сейчас нет данных (нет цели, эффектов или включённых модулей), в редакторе показывается
заготовка-превью, чтобы его всё равно можно было поставить на место.
Элементы, которые вы ни разу не двигали, сами подстраиваются под разрешение окна и соседние ванильные виджеты.

### Темы
Восемь встроенных тем: **amber, ocean, violet, crimson, mint, mono, sunset, ice**.
Тема задаёт акцент, второй цвет градиента, фон, основной и приглушённый текст — и сразу применяется
к ClickGUI, HUD, NameTags, TargetHUD и водяному знаку. Выбор: чип **THEMES** в ClickGUI или
`/goldish theme <id>`; список — `/goldish theme list`. Тема сохраняется в конфиге.

### ClickGUI
* Открытие — **Right Shift** (меняется в настройках управления Minecraft, категория Goldish).
* Верхняя «стеклянная» панель: логотип, слово-марка с версией и чипы **THEMES**, **CONFIG**, **ALTS**;
  больше не перекрывает ватермарк HUD (HUD под GUI скрывается).
* Панели категорий — стеклянные карточки с акцентной шапкой и счётчиком включённых модулей; ширина
  подстраивается под экран, поэтому все три категории всегда влезают целиком.
* Перетаскиваемые панели, прокрутка колесом, скроллбар.
* Строки настроек: переключатели, слайдеры (тянуть), режимы (ЛКМ/ПКМ), цвет (клик — следующий оттенок).
* **ПКМ по модулю** — развернуть настройки, **СКМ** — назначить клавишу (ESC — отмена).
* Быстрые анимации: GUI раскрывается и настройки выезжают за несколько кадров.

### Обмен конфигами
* При первом запуске клиент сам генерирует ключ вида `XXXX-XXXX-XXXX` и хранит его в конфиге (`shareKey`).
* Код конфига выглядит так: `GS1:<ключ>:<CRC32>:<base64url>` — внутри gzip-сжатый JSON настроек
  (модули, все значения, раскладка HUD/GUI и тема), обёрнутый в XOR-поток от ключа и защищённый контрольной суммой.
  XOR здесь не шифрование, а компактная обфускация; CRC ловит обрезанные и испорченные коды.
* Экспорт/импорт: чип **CONFIG** в ClickGUI (код копируется в буфер и читается из буфера) или команды ниже.
* Аккаунты и список друзей в код **не попадают** — они остаются только на вашем компьютере.


### Alt Manager
* Открыть: кнопка **ALTS** справа сверху в ClickGUI, такие же кнопки на титульном экране и в списке серверов,
  либо команда `/goldish alt gui`.
* Ник — 3–16 символов (`a-z`, `A-Z`, `0-9`, `_`). Вход — двойной клик по аккаунту или **LOGIN**, удаление — **DELETE**,
  **BACK** / ESC — назад.
* Активный аккаунт помечается **ACTIVE**, при наведении на строку виден полный UUID.
* Аккаунты **оффлайн** (cracked): UUID вычисляется как `OfflinePlayer:<ник>`, поэтому они подходят для серверов
  с `online-mode=false`. Для премиум-аккаунтов используйте официальный лаунчер.
* Новый ник применяется сразу, но уже открытое соединение остаётся со старым — переподключитесь к серверу.

## Управление
| Действие | Клавиша |
| --- | --- |
| Открыть/закрыть ClickGUI | Right Shift |
| Редактор HUD (тянуть элементы) | T (открытый чат) |
| Назначить бинд модуля | СКМ по модулю в GUI |
| Удалить бинд | Delete / Backspace при назначении |
| Alt Manager | кнопка ALTS или `/goldish alt gui` |
| Темы | чип THEMES или `/goldish theme <id>` |
| Обмен конфигами | чип CONFIG или `/goldish config gui` |

## Команды
```
/goldish friend add <ник>      # добавить друга
/goldish friend remove <ник>   # удалить друга
/goldish friend list           # список друзей
/goldish alt add <ник>         # добавить альт
/goldish alt remove <ник>      # удалить альт
/goldish alt list              # альты, активный помечен
/goldish alt login <ник>       # войти (создаст аккаунт, если его нет)
/goldish alt gui               # открыть Alt Manager
/goldish toggle <модуль>       # включить/выключить модуль
/goldish list                  # все модули и их состояние
/goldish theme <id>            # применить тему (список — /goldish theme list)
/goldish theme list            # список встроенных тем
/goldish config key            # показать ключ и скопировать его в буфер
/goldish config export         # скопировать код конфига в буфер
/goldish config import         # применить код конфига из буфера
/goldish config gui            # открыть экран обмена конфигами
```
Короткий алиас — `/gs`. Работает автодополнение имён модулей и тем.

## Конфиг
Всё хранится в `config/goldish/config.json`: тема (`"theme"`), ключ обмена (`"shareKey"`), состояния модулей,
все настройки, позиции панелей GUI (`"panels"`), позиции перетащенных HUD-элементов (`"hud"`),
цвета акцента/фона/текста, список друзей и список альтов.
Сохраняется при закрытии GUI, смене настроек, отпускании HUD-элемента и выходе.

## Математика
Общий фундамент для будущих модулей:
* `MathUtil` — clamp/lerp/map, smoothstep и smootherstep, независимое от FPS сглаживание (`expSmooth`),
  работа с углами (кратчайшая разница, `lerpAngle`, wrap), геометрия (расстояния, площадь полигона),
  случайные числа и гаусс, кривые (Безье, Catmull-Rom, билинейная интерполяция).
* `Easing` — 15 стандартных кривых (Sine/Quad/Cubic/Expo/Circ/Back/Elastic/Bounce) для анимаций GUI и HUD.
* `Noise` — детерминированный value-noise и fBm (1D/2D) с сидом; пригодится для частиц, пульсаций и органики.
* `Projection` — единый world-to-screen проектор для ESP, NameTags и TargetESP (учитывает FOV, интерполяцию позиции и кэш видимости).


## Сборка
Нужен **JDK 21**.
```bash
./gradlew build          # готовый jar в build/libs
./gradlew runClient      # запуск клиента в dev-окружении
./gradlew runClientGameTest   # автотест: HUD/GUI/AltManager, криты, AimAssist, TargetHUD/ESP,
                              # NameTags/ESP (Box/Chams), темы, обмен конфигами, AutoSprint, математика, редактор HUD
```
Скриншоты теста складываются в `build/run/clientGameTest/screenshots/`.

### Стек рендера
`Render2D` работает поверх ванильного `DrawContext`, поэтому корректно дружит со скейлом GUI,
скиссором и порядком отрисовки. Скругления и тени — процедурные антиалиасные 9-slice текстуры,
градиенты — собственный `GradientQuadElement`. Текстуры пересоздаются после перезагрузки ресурсов,
так что F3+T и смена паков ничего не ломают.
