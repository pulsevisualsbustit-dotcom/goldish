# Goldishka Loader

Полноценный графический лаунчер для клиента **Goldish** на Minecraft **1.21.11** и Fabric **0.19.5**.
Он сам скачивает игру, библиотеки, ресурсы, Fabric Loader, Fabric API и Goldish, а затем запускает клиент.
Никаких сторонних лаунчеров и ручной сборки — только этот интерфейс.

## Что нужно

Для готовой сборки:

- Windows 10/11 (проверено на Windows 10/11 x64).
- **Java 21** (JDK или JRE). Лаунчер ищет её в `JAVA_HOME`, `PATH` и `C:\Program Files\Java`.
  Java 26, которая может стоять в `PATH`, не подойдёт для запуска — лаунчер сам выберет Java 21,
  если она установлена.
- Интернет для первого запуска: скачивается около 400 МБ (клиент, библиотеки, 4591 файл ресурсов).

Для запуска из исходников дополнительно нужны **Python 3.10+** (проверено на 3.13) и
**PyQt5** (`python -m pip install PyQt5`).

## Запуск

### Готовая сборка

Откройте папку `loader\dist\Goldishka Loader` и запустите `Goldishka Loader.exe`.
Это обычная переносимая папка: рядом с exe лежат `_internal`, `assets` и `goldish-1.0.0.jar`,
а при первом запуске создаются `config.json`, `game` и `logs`. Папку можно переносить целиком.
Не запускайте exe прямо из архива — сначала распакуйте её.

### Из исходников

Откройте папку `loader` и запустите:

```powershell
python "Goldishka Loader.pyw"
```

или просто дважды щёлкните по `Goldishka Loader.pyw`. Файл `.pyw` запускает интерфейс без чёрного
консольного окна.

При первом запуске появится заставка, затем лаунчер проверит папки и Java. Нажмите **«Играть»** —
начнётся установка. Следующие запуски проходят быстро: недостающие файлы проверяются по размеру и SHA-1.

## Интерфейс

| Раздел | Что делает |
| --- | --- |
| **Главная** | Приветствие, новости, быстрый запуск, живые серверы, друзья и режимы игры. |
| **Играть** | Список серверов с настоящим Minecraft server-list ping: онлайн, пинг, версия. Фильтры, добавление, изменение и удаление серверов, быстрый вход. |
| **Параметры запуска** | Ник, версия, память, Java, аргументы JVM и игры. Справа — состояние компонентов: Java, клиент, ресурсы, Fabric, Goldish, Fabric API. |
| **Моды** | Список `game/mods`, включение/выключение (`.jar` ↔ `.jar.disabled`), установка и удаление. Goldish и Fabric API ставятся автоматически. |
| **Ресурспаки** | Список `game/resourcepacks`, включение через `options.txt`, установка и удаление. |
| **Настройки** | Поведение лаунчера, папка игры, `config.json`, логи, сброс настроек. |
| **Внешний вид** | Четыре акцентные темы, четыре фона, пресеты, анимации и частицы. Изменения применяются сразу и сохраняются. |

## Файлы и папки

```
loader/
├── Goldishka Loader.pyw   точка входа без консоли (запуск из исходников)
├── config.json            настройки при запуске из исходников
├── goldishka/             исходники лаунчера (Python + PyQt5)
├── assets/                логотипы, фоны, новости, превью тем
├── build_exe.ps1          сборка папки dist\Goldishka Loader
├── game/                  папка Minecraft при запуске из исходников
│   ├── versions/          клиент и профиль Fabric
│   ├── libraries/         библиотеки
│   ├── assets/            ресурсы
│   ├── mods/              Goldish, Fabric API и ваши моды
│   ├── resourcepacks/     ресурспаки
│   ├── saves/             миры
│   └── logs/
│       └── launcher-console.log   stdout игры при выключенной консоли
├── dist/
│   └── Goldishka Loader/  готовая переносимая сборка
│       ├── Goldishka Loader.exe
│       ├── _internal/     Python, Qt и плагины
│       ├── assets/        картинки интерфейса
│       ├── goldish-1.0.0.jar
│       ├── config.json    создаётся при первом запуске
│       ├── game/          создаётся при первом запуске
│       └── logs/
└── logs/
    └── launcher-error.log         ошибки запуска самого лаунчера
```

`config.json` и `game/` можно переносить вместе с папкой `loader` или `dist\Goldishka Loader`.
Если удалить `game/`, лаунчер скачает всё заново. Настройки при этом сохранятся.

## Сборка exe

Сначала соберите jar клиента в корне проекта (`.\gradlew.bat build`), затем в папке `loader`:

```powershell
python -m pip install pyinstaller pillow
.\build_exe.ps1
```

Скрипт соберёт `dist\Goldishka Loader`, скопирует туда `goldish-1.0.0.jar` и `README.md`.
Используется режим `--onedir`: папка запускается быстрее и не требует распаковки во временную
директорию при каждом старте (однофайловая сборка на Windows иногда падает с ошибкой
`Could not create temporary directory`).

## Моды

Goldish берётся из `build/libs/goldish-1.0.0.jar` (или из `loader/goldish*.jar`, или уже лежит в
`game/mods`). Чтобы пересобрать клиент:

```powershell
.\gradlew.bat build
```

После сборки запустите лаунчер: свежий `goldish-1.0.0.jar` будет скопирован в `game/mods`
автоматически. Fabric API лаунчер скачивает с Modrinth, а при недоступности — с maven Fabric.

Выключение мода переименовывает файл в `*.jar.disabled`, поэтому его легко вернуть обратно.
Изменения вступают в силу после перезапуска Minecraft.

## Ресурспаки

Включение и выключение меняет строку `resourcePacks:` в `game/options.txt`. Если файла ещё нет,
запустите игру один раз — Minecraft создаст его сам. После изменения перезапустите игру.

## Java и память

По умолчанию лаунчер выбирает Java 21. Если её нет:

1. Установите JDK 21 (например, Eclipse Temurin 21).
2. Откройте **«Параметры запуска» → Java → Обзор** и укажите `...\jdk-21\bin\java.exe`.
3. Память регулируется ползунком. Для 1.21.11 с Fabric обычно достаточно 3–4 ГБ.

Если Java не найдена, лаунчер не начнёт установку и покажет ошибку в оверлее запуска.

## Частые проблемы

- **«Java не найдена»** — укажите путь к `java.exe` версии 21+ в параметрах запуска.
- **Долгая первая установка** — скачиваются ресурсы; прогресс и лог видны в оверлее.
- **Игра не стартует** — откройте `game/logs/launcher-console.log`; там вывод Java и Minecraft.
- **Лаунчер не открывается** — запускайте `Goldishka Loader.exe` из папки `dist\Goldishka Loader`
  целиком (рядом должна лежать `_internal`). Для запуска из исходников проверьте
  `logs/launcher-error.log` и наличие PyQt5.
- **Сервер оффлайн** — это реальный ping; проверьте адрес и порт (по умолчанию 25565).
- **Антивирус ругается на exe или `.pyw`** — добавьте папку лаунчера в исключения; он не содержит
  обфускации и запускает только Java из указанного пути.

## Технические детали

- Установка идёт по официальному манифесту Mojang (`piston-meta.mojang.com`), ресурсы — с
  `resources.download.minecraft.net`, профиль Fabric — с `meta.fabricmc.net`.
- Скачивание проверяется по SHA-1 и размеру; уже готовые файлы не перекачиваются.
- Запуск — отдельный процесс Java с `-Xmx`, `-Djava.library.path`, classpath из библиотек Mojang и
  Fabric, оффлайн-UUID и `--quickPlayMultiplayer` при входе на сервер.
- Поток установки — демон, поэтому лаунчер можно закрыть, не убивая уже запущенную игру.
- Внешних Python-зависимостей, кроме PyQt5, нет.
